## 📌 About MIT-WPU RIDERS
**MIT-WPU RIDERS** is the pioneering university motorcycle club in India, founded by passionate student riders and mentored by faculty at **MIT World Peace University (Kothrud, Pune)**. 

The club is dedicated to:
- **Discipline & Safety:** Rigorous adherence to ATGATT (All The Gear, All The Time) and road safety doctrines.
- **Brotherhood & Fellowship:** Connecting passionate motorcyclists across Engineering, Management, Design, and Science disciplines.
- **Endurance & Touring:** Organizing structured expeditions across Maharashtra's Western Ghats, coastal Konkan circuits, and charity events like the *Distinguished Gentleman's Ride (DGR)*.
- **National Recognition:** First institute-level riding club in India formally recognized and awarded by Bosch & Radon Riders.

---

## 🚀 Key Features

- **🏆 Bosch & Radon Riders Award Showcase:** Highlighting national accolades and institutional backing.
- **📅 Interactive Ride Expedition Calendar:** Detailed ride overviews, itineraries, pace guidelines, meeting points, and mandatory gear check.
- **🛡️ Safety Doctrine & Hand Signal System:** Interactive visual guide for pack riding signals and T-CLOCS pre-ride inspection checklists.
- **📸 High-Res Media Gallery & Instagram Integration:** Authentic event moments, badge ceremonies, and ride reels.
- **📝 Student Registration & Induction Portal:** Interactive form with input validation for student onboarding and emergency contacts.
- **⚡ Supercharged Performance & Dark Mode Aesthetics:** Dark carbon fiber aesthetic, smooth glassmorphism, responsive navigation, and micro-interactions.

## 🔍 SEO & Web Standards Optimization

This web application is fully optimized for modern search engines:
- **Descriptive Meta Hierarchy:** Semantic `<title>`, meta descriptions, and targeted keyword tags.
- **Open Graph Protocol & Twitter Cards:** Rich preview cards for social media sharing across WhatsApp, LinkedIn, Instagram, and X (Twitter).
- **Structured Data (Schema.org JSON-LD):** Implements `SportsClub`, `Organization`, and `WebSite` graph entities including geo-coordinates, university affiliation, logo, and social handles.
- **Crawler Directives:** Dedicated [`robots.txt`](https://sujansinhdodia-blip.github.io/MIT-WPU-RIDERS/robots.txt) and [`sitemap.xml`](https://sujansinhdodia-blip.github.io/MIT-WPU-RIDERS/sitemap.xml).
- **Canonical URLs:** Canonical tags pointing directly to the deployed GitHub Pages URL.

## 🛠️ Local Development

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/sujansinhdodia-blip/MIT-WPU-RIDERS.git

# Enter project directory
cd MIT-WPU-RIDERS

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build production bundle:
```bash
npm run build
npm run preview
```
